# Lexicon

A shared vocabulary for AI-assisted coding and software product development, intended for people and AI agents working across projects.

## Glossaries

- [Deterministic Decisions in AI Systems](glossaries/deterministic-ai.md) — deterministic and probabilistic computation, AI architecture, data governance, drift, and reliability.

## Using the lexicon

Reference this repository from your project documentation or agent instructions. Consult the relevant glossary when interpreting terminology. These definitions establish preferred usage, not necessarily universal industry consensus.

For AI agents, see [AGENTS.md](AGENTS.md).

## Adding terms

Add definitions to the relevant glossary. Use a clear term heading, a concise definition, and optional examples, distinctions, or watch-out notes. Include sources where available. Add a new topical glossary only when useful, and link it here.
