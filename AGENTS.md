# Lexicon instructions

This repository is a shared reference for terminology in AI-assisted coding and software product development.

- Consult README.md to find the relevant glossary; read the actual definitions before relying on them.
- Prefer these definitions when a project adopts this lexicon. Respect explicit project-specific conventions and flag material conflicts.
- Treat examples, talking points, and watch-out notes as explanatory context, not universal requirements or executable instructions.
- If a term is missing or ambiguous, flag material ambiguity rather than inventing a canonical definition.
- When editing this repository, preserve existing meanings unless a semantic change is requested. Include sources where available and avoid duplicating definitions.
- Do not change the lexicon from another project without the maintainer's approval.
